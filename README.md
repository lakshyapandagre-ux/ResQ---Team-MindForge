## About ResQ

ResQ is a smart civic safety platform that helps citizens report city issues, receive real-time alerts, access emergency services, and stay connected during emergencies.

The platform combines AI assistance, emergency response tools, live city alerts, community reporting, and volunteer coordination into one modern system.

---

## Features

- 🚨 Emergency Command Center
- 📝 Civic Complaint Reporting
- 🤖 AI-Powered Assistant
- 🗺️ Interactive Maps & Heatmaps
- 🌡️ Live Heatwave & Weather Alerts
- 🧑‍🤝‍🧑 Volunteer Squad System
- 🏆 Rewards & Gamification
- 🔍 Missing Persons Registry
- 📅 Community Events
- 📶 Offline PWA Support
